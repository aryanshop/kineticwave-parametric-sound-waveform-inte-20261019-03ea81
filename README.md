# KineticWave: Parametric Sound Waveform & Interference Lab

## Overview
KineticWave is an interactive physics and acoustics educational laboratory built with vanilla HTML5, CSS3, and JavaScript. It allows students, educators, and audio enthusiasts to explore sound wave physics, harmonic superposition, acoustic beating, phase cancellation, and Lissajous patterns in real-time.

## Features
- **Interactive Wave Sources**: Configure up to 4 independent wave generators with adjustable frequency (50Hz - 880Hz), amplitude, phase shift (0&deg; - 360&deg;), and waveform type (Sine, Square, Triangle).
- **Real-Time Interference Visualization**: Smooth HTML5 Canvas animation displaying individual component waveforms along with their combined constructive/destructive interference pattern.
- **Preset Demonstrations**: One-click loading of classic acoustic phenomena including Unison, Acoustic Beats, Octave Harmony, Phase Cancellation, and Standing Waves.
- **Lissajous Phase Analysis**: Secondary canvas plotting 2-axis phase trajectories between wave sources.
- **Web Audio API Preview**: Optional real-time browser audio synthesis to hear the exact sound of your customized parametric waveforms.
- **Live Metrics**: Calculates combined maximum amplitude, beat frequency, approximate wavelength, and acoustic energy density.

## Local Run Instructions
1. Download or clone the project repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, package managers, or internet connection required.

## Static Project Notice
This project runs entirely client-side using vanilla web technologies without any external dependencies, tracking, or network requests.
